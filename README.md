# space-dodger
This is a space themed vertical scolling game - Samuel's first!

## First milestone

The first deployment is deliberately simple: a small Hello World page published with GitHub Pages. Once the deployment is confirmed, we'll start building the first playable version together.

## Run locally

Open `site/index.html` in a web browser.

## Deployment

Every push to `main` deploys the contents of `site/` to GitHub Pages using the workflow in `.github/workflows/deploy-pages.yml`.

If GitHub Pages has not been enabled for this repository yet, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
